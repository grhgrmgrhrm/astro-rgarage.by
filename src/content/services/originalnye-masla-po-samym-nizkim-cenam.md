## Как выбрать масло

### По допуску производителя

Самый надёжный способ — использовать масло, рекомендованное производителем автомобиля. Допуск указан в сервисной книжке или на сайте марки. Например:

- **VW** — 504.00 / 507.00 (LongLife), 502.00 / 505.00
- **BMW** — Longlife-01, Longlife-04
- **Mercedes** — 229.51, 229.52
- **Ford** — WSS-M2C913-C, WSS-M2C948-B
- **Toyota** — ILSAC GF-5, API SN

### По вязкости

- **5W-30** — универсальное, для большинства современных авто
- **5W-40** — для моторов с пробегом, для жаркого климата
- **0W-30 / 0W-40** — для холодных зим, лёгкий запуск до -35°C
- **10W-40** — для старых двигателей, полусинтетика

### По типу

- **Синтетика** — лучший вариант для современных двигателей
- **Полусинтетика** — для моторов с пробегом 150+ тыс. км
- **Минеральное** — для старых авто и спецтехники

### Какое масло подходит для моего автомобиля?

Позвоните нам по телефону +375 29 373-71-61 — назовите марку, модель, год и объём двигателя, и мы подберём масло по допуску производителя.

### Можно ли смешивать масла разных брендов?

В экстренной ситуации можно долить масло другого бренда с той же вязкостью и спецификацией. Но при замене лучше использовать одно масло — смешивание разных присадок может ухудшить свойства.

### Выдаёте ли вы чек для гарантии?

Да, мы выдаём чек с указанием масла, фильтра и работ. Если автомобиль на гарантии, этого достаточно для сохранения гарантийных обязательств.
